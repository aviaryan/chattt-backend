# Chattt Backend

⚡️ Backend for [chattt](https://github.com/aviaryan/chattt).


## Running

```sh
> git clone https://github.com/aviaryan/chattt-backend.git

> cd chatt-backend

> npm install

> npm run start
```


## Hosting it for free

You can use [Render](https://render.com/) to run this server for free. Currently, the server is running for free on https://chattt-backend.onrender.com.
